개구리소년 사건 기록 웹사이트

실행 방법
1. 압축을 푼 뒤 index.html 파일을 웹 브라우저에서 연다.
2. 상단 메뉴를 누르면 해당 콘텐츠로 가로 이동한다.
3. 화면에는 한 번에 하나의 콘텐츠 페이지만 표시된다.

주요 파일
- index.html: 전체 화면과 iframe 배치
- menu_box.html: 가로 메뉴
- profiles.html: 실종 아동 5명 프로필과 사진 삽입 영역
- content.css: 콘텐츠 페이지 공통 스타일
- content.js: 메뉴 선택에 따른 가로 이동 (기존 방식 유지)
- contents/: 콘텐츠별 HTML 파일
- images/: 콘텐츠에 삽입된 참고 이미지

실종 아동 사진 추가 방법
profiles.html은 아래 경로에서 실제 사진을 불러오도록 준비되어 있다.
- images/children/kim-jongsik.jpg
- images/children/park-chanin.jpg
- images/children/kim-younggyu.jpg
- images/children/cho-hoyeon.jpg
- images/children/woo-cheolwon.jpg

위 경로에 신뢰할 수 있는 출처에서 확인한 사진 파일을 넣으면 사진 영역에 표시된다.
사진 파일이 없으면 '사진 삽입 위치' 안내가 나타난다. 실제 사진이 아닌 임의의 이미지를 실종 아동 사진처럼 사용하지 않는다.

주의
콘텐츠 페이지에 삽입된 산길, 수색, 자료, 추모 풍경 이미지는 분위기를 설명하기 위해 생성한 참고 이미지이며 실제 사건 당시 촬영된 사진이 아니다. 사건 사실을 설명하는 자료와 구분해 사용한다.
프로필 이름과 실종 당시 나이는 연합뉴스의 2001년·1999년 보도와 대조해 기록했다.
